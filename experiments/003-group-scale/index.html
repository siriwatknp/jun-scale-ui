003 · Group scale

A component in group N renders at --scale × var(--scale-groupN, 1). Labels read value = base × global × gN factor.

1Defaults

/* nothing set */

Every group factor falls back to 1, so each component renders at its base size times the global scale.

2A container shrinks Controls

--scale-group5: 0.75

Controls render at 0.75. The Icon inside the Button keeps its own factor, so it stays 15px.

3Global scale and a group factor together

--scale: 1.2; --scale-group5: 0.75

The global scale applies to every group: a Control renders at 1.2 × 0.75 = 0.9, an Inline at 1.2.

4A component sets a smaller group

Button { --scale-group3: 0.8 }

The Button sets the Inline factor for what it holds. The Badge inside it shrinks, the Badge outside does not.

5The nearest value wins

--scale-group2: 1.5, and a Button inside sets --scale-group2: 0.8

Icons take the Icon factor from their nearest ancestor that sets it: 1.5 from the container, 0.8 inside the Button.
